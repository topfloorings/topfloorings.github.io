How to measure

  1. Measure the length and width of each room at the longest points.
  2. Divide an L-shaped room into two rectangles. Add each rectangle as a room.
  3. Include closets and spaces under doors.
  4. Find the box size on the product page. Enter it in "Sq ft per box".

How much extra flooring to order

Most straight installs need 10% extra for cuts and mistakes. Diagonal and herringbone patterns need more. Read the full guide: How much extra flooring should you order for waste.
